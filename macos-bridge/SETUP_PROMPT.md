# Claude Code に貼り付ける文章

**短くしてあります。貼り付ける前に、必ず自分で読んでください。**
中身が分からないまま長い指示文を貼るのは、内容を読まずに書類にサインするのと同じです。

---

```
Keychron C100 8K というキーボードを、MIDIコントローラーとして使えるように
したいです。

道具と手順書はここにあります：
https://github.com/FingerDrumLabo/keychron-c100-midi

まずダウンロードして、中の AI_INSTRUCTIONS.md に書いてある手順に沿って
進めてください。

ただしその前に、「これから何をするのか」「私のパソコンに何が起きるのか」を
説明してください。私が納得してから作業を始めてください。

私はプログラミングが分かりません。専門用語は使わずに話してください。
```

---

## 貼り付ける前に、この文章の意味

| 行 | 何を頼んでいるか |
|---|---|
| 1〜2行目 | やりたいことを伝えている |
| 3〜4行目 | 道具の置き場所を教えている |
| 5〜6行目 | その中の手順書に従ってほしい、と頼んでいる |
| 7〜9行目 | **作業の前に説明させている。ここが一番大事** |
| 10行目 | 分かる言葉で話してもらう |

**怪しいことは何も頼んでいません。** 心配なら、この文章自体を AI に見せて
「これは安全ですか」と聞いてみてください。それも立派な使い方です。

## 知っておくと安心なこと

Claude Code は、**何かを実行する前にあなたに確認を求めます。**
「このコマンドを実行していいですか？」と毎回聞かれるので、
**あなたが許可しない限り、勝手に何かが起きることはありません。**

内容が分からなければ、その場で「これは何をするコマンドですか」と
聞き返してかまいません。

---

## セットアップ後に、話しかけるだけでできること

| 言うこと | 起きること |
|---|---|
| 「色が変わるのを遅くして」 | 叩いたときの色の変化がゆっくりになる |
| 「色が変わるのを止めて」 | 色が固定される |
| 「光り方は16番と20番だけにして」 | その2つだけを行き来する |
| 「右上のパッドも普通のパッドに戻して」 | 100個全部がMIDIパッドになる |
| 「並びを単純な順番にして」 | 左から順に並ぶ配列に変わる |
| 「キーボードを元に戻して」 | 買ったときの状態に戻る |
