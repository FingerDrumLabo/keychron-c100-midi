# Keychron C100 8K を MIDI コントローラーにする

100個のキーを、そのまま100個のMIDIパッドにします。
ファームウェアの書き換えは不要です。

- 100パッド、それぞれ別のMIDIノート
- MIDIチャンネル1、ベロシティ127
- 押しても文字は打たれません
- パッドからキーボードの光り方を切り替えられます
- 叩くたびに色が少しずつ変わります
- **いつでも工場出荷状態に戻せます**

---

## 必要なもの

| | |
|---|---|
| Mac | **macOS 13 以降。** メモリ4GB以上、空き容量3GBほど。Intel / Apple Silicon どちらでも動きます。Windows / Linux 版はありません |
| Keychron C100 8K | USBケーブルで接続 |
| [Claude Code](https://claude.com/claude-code) | セットアップを代行してもらいます。**Proプラン以上が必要（月$20）** |
| Xcode Command Line Tools | **約1.8GB**。未インストールなら `xcode-select --install` |
| DAW | **MIDI入力を受けられるものなら何でも**。Ableton Live / Logic Pro / Cubase / Studio One / Reaper / FL Studio / Bitwig / MainStage / GarageBand など |

---

## 先に知っておいてほしいこと

**macOS 用です。** Windows / Linux では動きません。

正確には「作者が試していない」というだけで、理屈の上では Windows でも実現できる
はずです。ただし仕組みがかなり変わります（キーボードを独占できないので入力を
握り潰す方式になる、仮想MIDIポートが標準で無いので loopMIDI などが要る）。
挑戦する分には歓迎ですが、**動作は保証できませんし、サポートもできません。**

Keychron がファームウェアを公開すれば、Windows でも普通に動くようになります。

**起動のたびにMacのパスワードが要ります。** キーボードからの入力を横取りして
文字が打たれないようにするために、管理者権限が必要だからです。Macがこれを
簡単に許さないのは、同じ仕組みで他人のパスワードを盗み見られてしまうためで、
当然の制限です。

**Claude Code は有料です。** 無料プランでは使えません。一番安い Pro プランで
月20ドル（年払いなら月17ドル）です。

ただし**セットアップは一度きりの作業**です。1ヶ月だけ契約して設定を済ませ、
解約しても構いません。**できあがったプログラムはあなたのMacに残るので、
解約後もそのまま動きます。** 再び必要になるのは、あとから設定を変えたく
なったときだけです。

ターミナルの操作に慣れている方は、Claude Code なしでも設定できます。
一番下の「手動でセットアップする」を見てください。

**同時押しは6個までです。** USBキーボードの規格上の制限です。

**キーボードの中身を書き換えます。** ただし書き換える前に必ずバックアップを
取るので、いつでも購入時の状態に戻せます。戻し方は下に書いてあります。

**ファームウェアが公開されたら、もっと良い方法が使えるようになります。**
Keychron が C100 のファームウェアを公開すれば、Mac も常駐プログラムも
パスワードも不要で、Windows でも動くようになります。それまでの繋ぎです。

## セットアップ

### 1. Claude Code を入れる

[claude.com/claude-code](https://claude.com/claude-code) から
**デスクトップアプリ**を入れてください。普通のアプリと同じインストールです。

### 2. 文章を貼り付ける

Claude Code を開いて、[SETUP_PROMPT.md](SETUP_PROMPT.md) の枠の中をコピーして
貼り付けます。**ターミナルを開く必要はありません。**

貼り付ける文章は10行だけです。**必ず自分で読んでから貼ってください。**
何を頼んでいるのかは SETUP_PROMPT.md に一行ずつ書いてあります。

Claude Code は**何かを実行する前に必ず確認を求めます。**
あなたが許可しない限り、勝手に何かが起きることはありません。

Claude Code はまず、これから何をするプログラムなのかを説明してくれます。
納得してから進めてください。

そのあとは、ダウンロード・ビルド・キーボードの設定・起動アイコンの作成まで
全部やってくれます。

> **なぜこの方法なのか**
>
> 知らない人が作ったプログラムを、中身も見ずに管理者権限で動かすのは
> 本来やってはいけないことです。この方法なら、**入れる前にあなたのAIに
> 中身を読ませて、質問できます。**
>
> ついでに、すべてあなたのMacの中で作られるので、macOS の
> 「開発元を確認できません」という警告も出ません。

### 3. 起動する

デスクトップにできた **「C100 MIDI 起動」** をダブルクリック。
パスワードを入力すると、こう表示されます。

```
c100grab: keyboard seized -- its keys will not type anything
MIDI source published: "Keychron C100"
play. Control-C to stop.
```

**このウィンドウは開いたままにしてください。** 閉じると止まります。

### 4. DAW側で有効にする

このツールは、Macに **「Keychron C100」という名前のMIDI機器**を1つ作ります。
DAWから見れば、普通のMIDIキーボードを挿したのと同じ状態です。
**MacのMIDIを受けられるDAWなら、どれでも使えます。**

やることはどのDAWでも同じで、この3つです。

1. **DAWのMIDI設定で「Keychron C100」を有効にする**
2. **トラックの入力を「Keychron C100」にする**
3. **そのトラックを録音待機、またはモニターONにする**

⚠️ **ブリッジを先に起動してから、DAWを開いてください。**
順番が逆だと認識されないことがあります。

#### Ableton Live

1. 環境設定 → Link/Tempo/MIDI
2. 入力ポートの **Keychron C100** の「**トラック**」にチェック
3. MIDIトラックの **MIDI From** を **Keychron C100** に
4. トラックを**録音待機**（丸ボタン）にする

#### Logic Pro / GarageBand / MainStage

MIDI入力は自動で有効になります。**ソフトウェア音源のトラックを選ぶだけ**で
鳴るはずです。鳴らない場合はトラックが選択・録音待機されているか確認してください。

#### Cubase / Studio One / Reaper / FL Studio など

だいたい次の流れです。

1. 環境設定やデバイス設定の **MIDI入力** の一覧に「Keychron C100」があるので、
   それを**有効（アクティブ）**にする
2. トラックの**入力**として選ぶ
3. トラックを**録音待機／モニターON**にする

**メニューの正確な場所は、Claude Code に聞くのが早いです。**

> 「Cubaseで Keychron C100 というMIDI入力を有効にする方法を教えて」

セットアップに使ったAIがそのまま使えます。

#### 鳴らないとき、どちらの問題か切り分ける

ブリッジを起動した黒いウィンドウを見てください。パッドを叩いたときに

```
  pad 37  note 73  ON
```

のような行が出ていれば、**MIDIはちゃんと出ています。** その場合は
**DAW側の設定の問題**なので、上の3ステップを見直してください。

何も出ないなら、**キーボードとMacの間の問題**です。下の「困ったとき」へ。

## ノート配列

数字がMIDIノート番号です。手前が下、奥が上。

```
  104 105 106 107 | 112 113 114 115 |  35  33
  100 101 102 103 | 108 109 110 111 |  34  32
  ----------------------------------------------
   64  65  66  67 |  96  97  98  99 |  31  27
   60  61  62  63 |  92  93  94  95 |  30  26
   56  57  58  59 |  88  89  90  91 |  29  25
   52  53  54  55 |  84  85  86  87 |  28  24
  ----------------------------------------------
   48  49  50  51 |  80  81  82  83 |  23  19
   44  45  46  47 |  76  77  78  79 |  22  18
   40  41  42  43 |  72  73  74  75 |  21  17
   36  37  38  39 |  68  69  70  71 |  20  16
```

真ん中の8×8が、MIDI Fighter 64 と同じ配置です。**4×4のかたまり1つが、
Ableton の Drum Rack 1ページとぴったり一致します。**

| 場所 | ノート |
|---|---|
| 左下の4×4 | 36〜51 |
| 左上の4×4 | 52〜67 |
| 右下の4×4 | 68〜83 |
| 右上の4×4 | 84〜99 |
| 上の2列 | 100〜115 |
| 右の2列 | 16〜35 |

**素直に横一列で並んでいる方が好みなら**、セットアップし直すときに
`./c100setup install --layout launchpad` を使ってください。

## キーボードの光り方

**右上の角のパッド**を押すと、光り方が切り替わります。25種類あります。
このパッドだけMIDIノートを出しません。

叩くたびに色が少しずつ変わります。これはキーボードのメモリには保存されないので、
電源を切れば元の色に戻ります。

設定は `keycode_map.json` で変えられます。

| 項目 | 説明 |
|---|---|
| `colorPerHit.enabled` | `false` にすると色が変わらなくなります |
| `colorPerHit.step` | 大きいほど速く色が変わります。2〜11くらいが実用範囲 |
| `rgbEffects` | 例えば `[16, 20]` と書くと、その2つだけを行き来します |
| `functionPads` | 削除すると、右上の角もMIDIパッドに戻ります |

変更したら、ブリッジを起動し直してください。

## 元に戻す

セットアップ時に `backup-日付.json` というファイルが作られています。

```
./c100setup restore backup-2026-09-01T131604Z.json
```

これでキーボードは購入時の状態に完全に戻ります。四隅のRGBキーも復活します。

## 困ったとき

**音は出るのに、文字も打たれてしまう**
キーボードの掴みに失敗しています。一度止めて、起動し直してください。

**起動しているのに、何も起きない**
**二重起動です。**これが一番多い原因です。キーボードの掴みは早い者勝ちなので、
2個目は静かに死にます。ターミナルでこれを実行してから起動し直してください。

```
sudo pkill -f '[c]100'
```

**Ableton に Keychron C100 が出てこない**
ブリッジを起動してから Ableton を開いてください。

**MIDIランプは光るのに、音が鳴らない**
トラックの MIDI From が Keychron C100 になっているか、
録音待機（丸ボタン）が入っているか確認してください。

**`c100setup` がキーボードを見つけられない**
Keychron Launcher を開いていませんか。Launcher と設定用の通り道を
取り合ってしまうので、閉じてから実行してください。

## 仕組み（興味がある人向け）

キーボードは「文字」を送る機械、DAWは「音符」しか受け取りません。
言葉が違うだけなので、間に通訳を置いています。

1. **キーボードの設定を書き換える** — 出荷時は全キーが同じ信号を送るので、
   どのキーを押したか区別できません。Keychron Launcher が使うのと同じ通り道で、
   100個に別々の信号を割り当てます。
2. **キーボードを掴む（`c100grab`）** — 管理者権限で、C100のキーボード部分だけを
   排他的に開きます。これで押しても文字が打たれなくなります。
3. **MIDIに変換する（`c100send`）** — 通常権限で動き、仮想MIDIポートを作って
   ノートを送ります。管理者権限で作ったMIDIポートは Live から使えなかったので、
   2つのプログラムに分けています。

マウスと設定用の通り道はわざと掴んでいません。ブリッジを動かしたまま
Keychron Launcher が使えます。

## 手動でセットアップする（ターミナルが分かる人向け）

Claude Code を使わない場合の手順です。**ソースコードを自分で読んで理解できる方だけ**
このやり方を使ってください。中身を確認せずに管理者権限のプログラムを動かすのは
危険です。

```
# 1. ビルド（Xcode Command Line Tools が必要）
swiftc -O -o c100setup c100setup.swift
swiftc -O -o c100grab  c100grab.swift
swiftc -O -o c100send  c100send.swift

# 2. キーボードを設定（バックアップは自動で作られます）
./c100setup install

# 3. 起動（Ableton を開く前に）
sudo ./c100grab | ./c100send

# 元に戻す
./c100setup restore backup-????.json
```
