# AIへの作業手順

このファイルは、Claude Code に読ませるための作業手順書です。
（人が読んでも構いませんが、専門的な内容です）

## 前提

- macOS 13 以降。Intel / Apple Silicon どちらでも可
- Keychron C100 8K が USB で接続されている
- 利用者はプログラミングの知識がない。専門用語を避けて説明すること

## 手順

### 1. 開発ツールの確認

`swiftc --version` と `xcode-select -p` を確認する。
使えない場合は `xcode-select --install` を実行し、利用者に次を伝えて待つこと。

- 約1.8GB のダウンロードがあること
- 回線によっては30分ほどかかること
- 一度入れれば二度と必要ないこと
- 終わったら再開すること

### 2. ビルド

```
swiftc -O -o c100setup c100setup.swift
swiftc -O -o c100grab  c100grab.swift
swiftc -O -o c100send  c100send.swift
```

sudo は不要。失敗したらエラー全文を利用者に見せること。

### 3. キーボードの確認

```
./c100setup status
```

見つからない場合、利用者に次を確認する。

- USB ケーブルで接続されているか
- Keychron Launcher（ブラウザの設定ページ）を閉じているか

### 4. キーボードの設定

```
./c100setup install
```

現在のキー配置を自動でバックアップしてから、100個のキーに別々のキーコードを
書き込む。`100/100` と出れば成功。失敗した数が出た場合はもう一度実行する。

利用者には「今キーボードの設定が書き換わったこと」「バックアップがあるので
いつでも元に戻せること」を伝えること。

### 5. 起動用ファイルの作成

利用者のデスクトップに、ダブルクリックで起動できる `.command` ファイルを作る。
**次の点を必ず守ること。**

- **道具の置き場所を絶対パスで直接書く。**
  `dirname $0` のように「このスクリプトのある場所」から探す書き方は使わない。
  このファイルはデスクトップに置かれるため、それでは道具を見つけられない
- 起動前に古いプロセスを止める
  （例：`sudo pkill -f 'KeychronC100MIDI/[c]100'`）。
  二重起動すると2つ目は静かに動かなくなる
- 本体は `sudo <絶対パス>/c100grab | <絶対パス>/c100send`
- 道具が見つからない場合は、その旨を表示して止まる
- ダブルクリックで開いたウィンドウが、読む前に閉じないようにする
- 作成後、ファイルの中身を利用者に見せて説明する

### 6. 最後の説明

次の4点を、専門用語を使わずに伝えて終わること。

1. デスクトップのアイコンをダブルクリックすれば起動すること
2. Mac のパスワードを聞かれる理由（キーボードの入力を横取りして、文字が
   打たれないようにするため）
3. 起動したウィンドウを閉じないこと。止めるときは Control + C
4. Ableton 側の設定（環境設定 → Link/Tempo/MIDI で「Keychron C100」の
   トラックにチェック → トラックの MIDI From を Keychron C100 に →
   録音待機をオン）。**先にアイコンを起動してから Ableton を開くこと**

## やってはいけないこと

- `.swift` ファイルの中身を書き換えない。動作確認済み
- sudo を使うのは起動用ファイルの中だけ。ビルドと設定に sudo は不要
- ビルド済みのプログラムを外部からダウンロードしない。
  必ず利用者のパソコン上でソースからビルドする

## 想定される不具合

| 症状 | 原因 |
|---|---|
| 音は出るが文字も打たれる | キーボードの排他確保に失敗している |
| 起動しているのに何も起きない | 二重起動。掴みは排他なので2つ目は静かに死ぬ |
| Ableton に出てこない | ブリッジより先に Ableton を起動した |
| `c100setup` がキーボードを見つけられない | Keychron Launcher が設定用チャンネルを掴んでいる |

## 設定の変更

`keycode_map.json` を編集して、ブリッジを再起動すれば反映される。

| 項目 | 意味 |
|---|---|
| `colorPerHit.enabled` | 叩くたびに色を変えるか |
| `colorPerHit.step` | 変化の速さ。2〜11 が実用範囲。大きいほど速い |
| `rgbEffects` | 例 `[16, 20]`。書くとその番号だけを巡回する。0〜24 |
| `functionPads` | 光り方切り替えに使うパッド。消すと100個全部が MIDI に戻る |

配列そのものを変える場合は `./c100setup install --layout launchpad` を使う。
