# これは旧バージョンです

ここにあるのは、**Keychron が C100 8K の設計図を公開する前**に作った、
Mac 側のソフトで MIDI 化する方法です。1本目の動画で紹介したものです。

**今は使う必要がありません。** 設計図が公開されたので、
キーボード本体を MIDI 機器にできるようになりました。
[一つ上のフォルダの README](../README.md) を読んでください。

新しい方法の利点：

- Mac が要らない（Windows / Linux / iPad でも動く）
- 常駐するプログラムが要らない
- パスワードが要らない
- 同時押しの制限が無い（旧版は6個まで）
- 起動作業が要らない。挿すだけ

記録として残してあります。
