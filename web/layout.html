MIDI配列変更ページMIDI Layout Editor

Keychron C100 8K の、どのキーがどの音を鳴らすかを自由に変えられます。Change which note each key on the Keychron C100 8K sends.

使う前に
  • 先に MIDIコントローラーにするページ で書き込みを済ませてください
  • Chrome / Edge で開いてください
  • Keychron Launcher を開いていると接続できません。閉じてください
  • 書き込みモードに入る必要はありません。普通に挿したままで変更できます
Before you start
  • Flash the keyboard first on the MIDI controller page
  • Use Chrome or Edge
  • Close Keychron Launcher — it holds the connection this page needs
  • No flashing mode needed. Just leave the keyboard plugged in normally
未接続Not connected

並びLayout

マスをクリックして選び、下の欄で音を決めます。
手前が下、奥が上。実物のキーボードと同じ向きです。 Click a pad to select it, then set its note in the bar below.
The grid matches the keyboard: nearest row at the bottom.

プリセットPresets

プリセットを選んでから、必要なところだけ直すのが早いです。Start from a preset, then adjust only the pads you need.

困ったときIf something goes wrong

つながらない
Keychron Launcher が開いていませんか。閉じてから、もう一度お試しください。

音が変わらない
書き込んだあと、DAW を開き直してみてください。

元に戻したい
「フィンガードラム研究所式」を選んで書き込めば、最初の並びに戻ります。

It won't connect
Is Keychron Launcher open? Close it and try again.

The notes didn't change
Try restarting your DAW after writing.

I want the original layout back
Choose "FingerDrum Labo layout" and write it — that restores the default.
