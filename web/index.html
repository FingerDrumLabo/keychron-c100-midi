Keychron C100 8K を
MIDIコントローラーにするページ

始める前に
  • Keychron C100 8K 専用です。他の機種には使わないでください
  • 書き込むとキーボードとして文字が打てなくなります（元に戻せます）
  • Chrome / Edge で開いてください。Safari では動きません
  • 書き込み中はUSBを抜かないでください
  1. C100 の USBケーブルを抜きます
  2. 左上の角のキーを押しっぱなしにします
  3. 押したまま USBを挿します。3秒ほどしてから離します
  4. 下のボタンを押し、出てきた一覧から DFU in FS Mode を選びます
    環境によっては表示名称が異なる場合があります。

書き込んだあと

成功すると 「Keychron C100 8K」という MIDI 機器として認識されます。 お使いの DAW の MIDI 設定で有効にして、トラックの入力に指定してください。

送信される MIDI は チャンネル 1、ベロシティは 127 固定です。 ノート番号は 16〜115（Ableton や Logic の表記で E-1 〜 G7）。

中央の 8×8 は 36〜99（C1 〜 D#6）で、MIDI Fighter 64 と同じ並びです。 4×4 のかたまりひとつが、Ableton の Drum Rack 1ページとそのまま一致します。

元に戻したいときは

Keychron Launcher でキーを普通の文字に 割り当て直せば、キーボードとして使えます。書き込み直す必要はありません。
購入時の状態に完全に戻したい場合は、 GitHub にある 公式ファームウェアを同じ手順で書き込んでください。

うまくいかないとき

一覧に何も出てこない
キーボードは DFU in FS Mode という名前で出てきます。何も出てこない場合は書き込みモードに入れていません。USBを抜いて、左上のキーを押しながら挿し直してください。 何度でもやり直せます。

途中で止まった
キーボードは書き込みモードのままです。USBを挿し直して、もう一度やってください。

Safari で開いている
この仕組みは Chrome か Edge でしか動きません。
