書き込んだあと

成功すると 「Keychron C100 8K」という MIDI 機器として認識されます。 お使いの DAW の MIDI 設定で有効にして、トラックの入力に指定してください。

送信される MIDI は チャンネル 1、ベロシティは 127 固定です。 ノート番号は 16〜115（Ableton や Logic の表記で E-1 〜 G7）。

中央の 8×8 は 36〜99（C1 〜 D#6）で、MIDI Fighter 64 と同じ並びです。 4×4 のかたまりひとつが、Ableton の Drum Rack 1ページとそのまま一致します。

元に戻したいときは

Keychron Launcher でキーを普通の文字に 割り当て直せば、キーボードとして使えます。書き込み直す必要はありません。

購入時の状態に完全に戻したい場合は、下のボタンから書き込めます。 Keychron 公式のキーマップをそのままビルドしたものを書き込みます。

うまくいかないとき

一覧に何も出てこない
キーボードは DFU in FS Mode という名前で出てきます。何も出てこない場合は 書き込みモードに入れていません。USBを抜いて、左上のキーを押しながら挿し直してください。 何度でもやり直せます。

途中で止まった
キーボードは書き込みモードのままです。USBを挿し直して、もう一度やってください。

Safari で開いている
この仕組みは Chrome か Edge でしか動きません。

After flashing

Your computer will see a MIDI device called “Keychron C100 8K”. Enable it in your DAW's MIDI settings and select it as a track input.

It sends on MIDI channel 1 with a fixed velocity of 127. Note numbers run from 16 to 115 (E-1 to G7 in Ableton and Logic).

The central 8×8 covers 36–99 (C1 – D#6), matching the MIDI Fighter 64 layout. Each 4×4 block lines up exactly with one page of an Ableton Drum Rack.

Going back

To type with the keyboard again, just reassign the keys in Keychron Launcher. You do not need to flash anything.

To restore it completely, use the button below. It writes a build of Keychron's own stock keymap.

If it doesn't work

Nothing appears in the list
The keyboard shows up as DFU in FS Mode. If nothing appears, it is not in flashing mode. Unplug it, hold the top-left key, and plug it back in. You can retry as many times as you like.

It stopped partway through
The keyboard is still in flashing mode. Plug it back in and try again.

You are using Safari
This only works in Chrome or Edge.
