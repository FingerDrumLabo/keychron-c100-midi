# Keychron C100 8K を MIDIコントローラーにする

100個のキーを、そのまま100個のMIDIパッドにします。

- **パソコンに何もインストールしません。** キーボード本体が MIDI 機器になります
- Mac / Windows / Linux / iPad、**どれでも動きます**
- 同時押しの制限なし（**49個同時を実機で確認**）
- ノート 16〜115、MIDIチャンネル 1、ベロシティ 127
- **Keychron Launcher も今まで通り使えます**（光り方の変更、キーの割り当て変更）

> このリポジトリは動画の付録です。
> Part 1（Mac側のソフトで実現した版）の道具は [`macos-bridge/`](macos-bridge/) に
> 残してありますが、**もう使う必要はありません。**

---

## ⚠️ 最初に読んでください

**このファームウェアは Keychron C100 8K 専用です。**
**他の Keychron 製品（V1 8K など）には絶対に書き込まないでください。**
書き込みツールが表示する機器IDはチップ共通のもので、機種を区別しません。
間違えて書き込んでも正しいファームウェアを焼き直せば直りますが、避けてください。

**書き込むと、キーボードとして文字が打てなくなります。** これは仕様です。
戻し方は下の「元に戻す」を読んでください。**とても簡単です。**

## 書き込む

### 用意するもの

- Keychron C100 8K と USBケーブル
- [`firmware/c100_8k_MIDI.bin`](firmware/c100_8k_MIDI.bin)（60KB）
- 書き込みツール（[QMK Toolbox](https://github.com/qmk/qmk_toolbox/releases) など）

### 手順

1. **USBケーブルを抜く**
2. **左上の角のキーを押しっぱなし**にして、USBを挿す
3. **3秒ほど押し続けてから離す**（これで書き込みモードになります）
4. 書き込みツールで `c100_8k_MIDI.bin` を選んで実行

⚠️ **書き込み中はUSBを抜かないでください。** 数秒で終わります。

ターミナルが使える方は、こちらでも書き込めます。

```
dfu-util -d 2e3c:df11 -a 0 -s 0x08000000:leave -D c100_8k_MIDI.bin
```

`-d 2e3c:df11` は必ず付けてください。他のDFU機器を巻き込まないためです。

### ダウンロードしたファイルが本物か確かめる

```
shasum -a 256 c100_8k_MIDI.bin
```

出てきた文字列が、これと一致すればOKです。

```
9ed6e70dbf2d9b6127563f2628111fff92ab1b7ce034f3dc16b3427ef9846099  c100_8k_MIDI.bin
fef3d684247055a99d45f0cbf12149226652b97b8c5c394bd762d35e5ad5944f  c100_8k_STOCK.bin
```

### このファイルは GitHub が作っています

`firmware/` に置いてあるファイルと、サイトが書き込むファームウェアは、
**GitHub Actions が公開ソースからビルドしたものそのもの**です。
作者の手元でビルドしたものではありません。

同じファイルは [リリース v1.1](../../releases/tag/v1.1) からダウンロードできます。
上のハッシュと一致します。

- ビルドの記録: [Actions タブ](../../actions)
- ビルドに使ったもの: Keychron/qmk_firmware `2025q3` + `keyboards/keychron/c100_8k/keymaps/`

### 自分でビルドしたものとは一致しません

QMK は**ビルドした日時をファームウェアの中に埋め込みます。**
そのため同じソースからビルドしても、**作るたびに別のファイル**になります。
コンパイラのバージョンが違っても変わります。

「自分でビルドしてハッシュを比べる」という確認はできません。
確認したい場合は、**リリース v1.1 のファイルとハッシュを比べてください。**
`latest` リリースは push のたびに作り直されるため、中身が変わります。

## 音の並び

数字がMIDIノート番号です。手前が下、奥が上。

```
  104 105 106 107 | 112 113 114 115 |  35  33
  100 101 102 103 | 108 109 110 111 |  34  32
  ----------------------------------------------
   64  65  66  67 |  96  97  98  99 |  31  27
   60  61  62  63 |  92  93  94  95 |  30  26
   56  57  58  59 |  88  89  90  91 |  29  25
   52  53  54  55 |  84  85  86  87 |  28  24
  ----------------------------------------------
   48  49  50  51 |  80  81  82  83 |  23  19
   44  45  46  47 |  76  77  78  79 |  22  18
   40  41  42  43 |  72  73  74  75 |  21  17
   36  37  38  39 |  68  69  70  71 |  20  16
```

真ん中の8×8が **MIDI Fighter 64 と同じ配置**です。
**4×4のかたまりひとつが、Ableton の Drum Rack 1ページとぴったり一致します。**

| 場所 | ノート |
|---|---|
| 左下の4×4 | 36〜51 |
| 左上の4×4 | 52〜67 |
| 右下の4×4 | 68〜83 |
| 右上の4×4 | 84〜99 |
| 上の2列 | 100〜115 |
| 右の2列 | 16〜35 |

並びを変えたい場合は [BUILD.md](BUILD.md) を見てください。

## DAW側の設定

パソコンから見ると、**普通のMIDIキーボードを挿したのと同じ**です。

1. DAWのMIDI設定で **Keychron C100 8K** を有効にする
2. トラックの入力をそれにする
3. そのトラックを録音待機／モニターON

**Ableton Live の場合**：環境設定 → Link/Tempo/MIDI で「Keychron C100 8K」の
**トラック**にチェック → トラックの **MIDI From** をそれに → **録音待機**をオン。

Logic Pro / GarageBand は自動で有効になります。ソフト音源のトラックを選ぶだけです。

## 元に戻す

### 文字を打てるようにしたいだけなら → 書き込み直し不要です

**[Keychron Launcher](https://launcher.keychron.com/) でキーを割り当て直すだけ**で、
普通のキーボードとして使えるようになります。**実機で確認済みです。**

**一部だけ戻すこともできます。** たとえば96個をMIDIパッドのまま残して、
4個だけ「録音」「再生」などのショートカットにする、といった使い方ができます。

### 購入時の状態に完全に戻したいなら

同じ手順で [`firmware/c100_8k_STOCK.bin`](firmware/c100_8k_STOCK.bin) を書き込んでください。
Keychron 公式のファームウェア（`keychron` キーマップ）をそのままビルドしたものです。

## よくある質問

**書き込みに失敗しました**
もう一度、左上のキーを押しながら挿し直してください。書き込みモードに入る仕組みは
チップの保護された領域にあるので、**何度でもやり直せます。**

**他のキーボードでも同じことができますか**
QMK対応で、メーカーが設計図を公開していて、有線で繋ぐものなら、
**同じ考え方で応用できるはずです。** [BUILD.md](BUILD.md) を読んでください。
ただし**私が実際に確認したのは C100 8K だけ**です。

**8000Hzポーリングに設定した方がいいですか**
**MIDIには効きません。** MIDIはキーボードとは別の通信方式（バルク転送）で
送られるためです。それより Launcher の**デバウンス設定を `Eager Per Key`** に
すると、叩いてから音が出るまでが速くなります。

**同じキーボードを2台使えますか**
使えます。ただし両方とも同じ名前で出てくるので、
1台ずつ名前やMIDIチャンネルを変えたファームウェアを作るのがおすすめです。
やり方は [BUILD.md](BUILD.md) にあります。
